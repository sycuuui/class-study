docs/REQUIREMENTS.md를 기준으로,
구현할 REST API를 docs/API.md에 문서로만 작성해줘.

포함할 내용:
- 모든 엔드포인트의 HTTP 메서드와 경로
- 요청 파라미터/요청 바디(JSON)
- 정상 응답 예시(JSON)
- 실패 응답 예시(JSON)
- HTTP 상태 코드와 에러 코드/메시지 정의
- 특히 수강신청/취소의 실패 케이스:
  - 정원 초과
  - 학점 초과
  - 시간 충돌
  - 중복 신청
  - 존재하지 않는 ID

규칙:
- 코드는 생성/수정하지 마
- 요구사항 문서에 없는 기능은 추가하지 마
- 문서는 평가자가 API.md만 보고 테스트를 작성할 수 있을 정도로 구체적으로 써줘
- 이 프롬프트 원문을 prompts/0003_api_design.md 로 기록해줘
