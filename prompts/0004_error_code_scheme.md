docs/API.md에서 에러 코드 체계를 다음 정책으로 변경해줘(문서만 수정, 코드 수정 금지).

정책:
1) HTTP 상태 코드는 표준대로 사용한다.
   - 비즈니스 규칙 위반은 409 Conflict를 사용한다(501 사용 금지).
   - /health가 준비되지 않은 경우는 503 Service Unavailable을 사용한다(준비되면 200).
2) error.code는 숫자 체계로 통일한다.
   - 500번대: 공통/리소스/요청 검증(학생/강좌/교수/신청내역 not found 포함)
   - 600번대: 수강신청(정원/학점/시간충돌/중복)
   - 700번대: 서버 준비/초기화(서비스 준비중)
3) 기존의 STRING_CODE(STUDENT_NOT_FOUND 등)는 문서에 '기존 코드명(alias)'로 병기하되, 기본은 숫자 코드로 한다.

산출물:
- docs/API.md의 관련 섹션과 모든 예시 응답의 code 값을 위 규칙에 맞게 일괄 수정
- 에러 코드 매핑 표(숫자코드 ↔ 의미 ↔ HTTP 상태 ↔ 기존 코드명)를 추가
